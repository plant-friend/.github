# .github – Shared templates and defaults for PlantFriend

This repository contains the files that apply to **all** repositories of the PlantFriend organization.
GitHub automatically uses them in every repo that does not define its own version, so we maintain them in one place only.

## What's inside

| File / folder | Purpose |
|---|---|
| `ISSUE_TEMPLATE/` | Forms for tasks, bugs, feature requests and epics |
| `pull_request_template.md` | Checklist shown when opening a pull request |
| `CONTRIBUTING.md` | How we work: branches, commits, reviews, definition of done |
| `SECURITY.md` | How to report security issues privately |
| `labels.yml` | Shared labels for all repositories |
| `.github/workflows/` | Reusable CI/CD building blocks *(coming soon)* |
